# Алгоритмы и структуры данных на C++

Учебный репозиторий с лабораторными работами по дисциплине «Алгоритмы и структуры данных» в СКФУ (Северо-Кавказский федеральный университет).

Работы охватывают два курса: от обработки файлов и основ объектно-ориентированного программирования до собственных контейнеров, сортировок, поиска и деревьев. Каждая реализованная лабораторная имеет отдельную консольную программу и цель CMake.

**Технологии:** C++20, CMake 3.20+, стандартная библиотека C++.

## Сборка и запуск

Нужны компилятор с поддержкой C++20, CMake версии не ниже 3.20 и инструмент сборки для выбранного генератора, например Make или Ninja. Для корректного отображения русских сообщений используйте терминал с поддержкой UTF-8.

### Из корня проекта

Создать конфигурацию Release и собрать конкретную лабораторную:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target c2-lab10
./build/course-2/lab10/c2-lab10
```

Имена исполняемых целей имеют вид `c1-labN` для первого курса и `c2-labN` для второго, где N - номер работы. Например, `c1-lab4` и `c2-lab8`. Путь к исполняемому файлу при сборке из корня сохраняет структуру `build/course-N/labM/`.

Собрать все подключённые работы:

```bash
cmake --build build
```

### Отдельная работа второго курса

Каждая реализованная работа второго курса также поддерживает самостоятельную конфигурацию. Например, для работы 10:

```bash
cmake -S course-2/lab10 -B build-lab10 -DCMAKE_BUILD_TYPE=Release
cmake --build build-lab10
./build-lab10/c2-lab10
```

Работы первого курса собираются через корневой CMake. Для отладки вместо `Release` можно указать `Debug`. Для измерений производительности второго курса используйте `Release`, результаты зависят от оборудования и условий запуска.

Примеры команд рассчитаны на Linux и одноконфигурационные генераторы. В многоконфигурационном генераторе конфигурация выбирается при сборке через `--config Release`, исполняемый файл может находиться в дополнительном каталоге `Release`. На Windows он имеет расширение `.exe`.

### Особенности запуска

- В работах первого курса встречаются интерактивные меню и ввод данных. В `course-1/lab1` есть исходные данные в `testFiles`, некоторые задания записывают туда результаты.
- Первая работа первого курса обращается к данным через пути `../lab1/testFiles/...`. Запускайте её с рабочим каталогом `course-1/lab1`. В CLion этот каталог можно указать в настройках запуска.
- Работы 1-8 и 10-13 второго курса запускают заранее подготовленные демонстрации без ввода. Работа 9 после примеров запрашивает целый ключ для удаления из BST.
- Работа 14 после демонстраций запрашивает предметы и вместимость рюкзака, затем две строки для LCS. Ввод строк выполняется целиком, с сохранением пробелов.
- Работа 15 запрашивает текст и образец, выводит все позиции КМП и проверяет эти строки на анаграмму.
- Работа 16 запускает меню библиотеки. Пути сохранения и загрузки задаются пользователем, сценарии из media повторяются из каталога лабораторной.
- Работа 17 запускает меню каталога транспорта с сортировкой, поиском и файлами. После ошибки сохранения можно выбрать другое имя. Сценарий из media также запускается из каталога лабораторной.
- Демонстрации и граничные случаи находятся в `main.cpp`. Отдельных тестовых целей для работ второго курса нет.

Пример запуска файловой лабораторной после сборки из корня:

```bash
cmake --build build --target c1-lab1
cd course-1/lab1
../../build/course-1/lab1/c1-lab1
```

## Материалы лабораторных

В зависимости от работы каталог содержит:

- `main.cpp` - точку входа, примеры использования и демонстрации.
- `.h` и `.cpp` - объявления и реализации классов и алгоритмов.
- `.tpp` - определения шаблонов, подключаемые из заголовков в работах, где используется такое разделение.
- `CMakeLists.txt` - описание цели сборки лабораторной.
- `README.md` - постановку задачи, теорию, описание реализации, результаты, анализ и выводы.
- `media/` - изображения результатов, графики и сохранённый вывод, если они предусмотрены работой.

Подробности конкретного варианта, ограничения и методика измерений приведены в отчёте соответствующей лабораторной. Реализации снабжены поясняющими комментариями на русском языке.
