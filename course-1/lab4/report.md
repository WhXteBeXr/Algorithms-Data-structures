## Ход выполнения

### Теоретическое обоснование

Статический массив имеет фиксированный размер, известный на этапе компиляции. Динамический массив размещается в куче с помощью оператора `new[]`, его размер определяется во время работы программы, а при нехватке места он может быть расширен. Память, выделенная через `new[]`, должна быть освобождена оператором `delete[]`.

Если класс владеет динамической памятью, необходимо соблюдать «правило трёх»: определить деструктор (освобождает память), конструктор копирования (создаёт независимую копию объекта) и оператор присваивания (корректно копирует данные в уже существующий объект, с проверкой самоприсваивания). Без них компилятор создаёт поверхностную копию, при которой два объекта указывают на одну область памяти, что приводит к двойному освобождению.

«Правило пяти» дополняет эти методы конструктором перемещения и оператором присваивания перемещением. Они не копируют данные, а передают указатель от временного объекта новому владельцу, после чего источник обнуляется. Это ускоряет работу с временными объектами.

Для безопасной работы класс использует исключения: `std::invalid_argument` (неверный размер), `std::out_of_range` (индекс вне диапазона), `std::underflow_error` (удаление из пустого вектора). Освобождение памяти в деструкторе соответствует принципу RAII.

Перегрузка операторов позволяет работать с объектами класса так же, как со встроенными типами. Оператор `+` для векторов выполняет конкатенацию, оператор `*` умножает каждый элемент вектора на число. Оба оператора не изменяют исходные объекты, а возвращают новый вектор.

## Контрольные вопросы

### 1. Что такое динамическая память и чем она отличается от статической?

**Динамическая память** выделяется во время выполнения программы с помощью `new` и освобождается с помощью `delete`.

**Статическая память** выделяется заранее и существует в течение всего времени работы программы. Например, память для глобальных и статических переменных.

### 2. Для чего используются операторы `new[]` и `delete[]`?

`new[]` выделяет память под массив объектов:

```cpp
int* array = new int[10];
```

Освобождается такая память оператором `delete[]`:

```cpp
delete[] array;
```

Для памяти, выделенной через `new[]`, обязательно использовать `delete[]`, а не обычный `delete`.

### 3. Что такое «правило трёх» и почему оно важно?

**Правило трёх** гласит: если класс самостоятельно управляет ресурсом, обычно необходимо определить:

1. деструктор;
2. конструктор копирования;
3. оператор копирующего присваивания.

Это важно, чтобы корректно копировать и освобождать динамическую память и избежать утечек или двойного удаления.

### 4. В чём разница между конструктором копирования и оператором присваивания?

Конструктор копирования создаёт новый объект на основе существующего:

```cpp
IntVector a(b);
```

Оператор присваивания копирует данные в уже существующий объект:

```cpp
a = b;
```

### 5. Что произойдёт, если не реализовать конструктор копирования для класса с указателем?

Будет использовано поверхностное копирование: скопируется только адрес, хранящийся в указателе.

В результате два объекта будут указывать на одну область памяти. Это может привести к:

- изменению данных сразу в двух объектах;
- двойному освобождению памяти;
- аварийному завершению программы.

### 6. Зачем нужен список инициализации? В каких случаях он обязателен?

Список инициализации позволяет инициализировать поля до выполнения тела конструктора:

```cpp
class Example {
private:
    int value;

public:
    Example(int value) : value(value) {}
};
```

Он обязателен для:

- константных полей;
- ссылочных полей;
- полей, у которых нет конструктора по умолчанию;
- вызова нужного конструктора базового класса.

### 7. Что такое `this` и для чего он используется в операторе присваивания?

`this` - указатель на текущий объект.

В операторе присваивания он используется для обращения к текущему объекту и проверки самоприсваивания:

```cpp
IntVector& operator=(const IntVector& other) {
    if (this != &other) {
        // копирование данных
    }
    return *this;
}
```

### 8. Почему в операторе присваивания нужна проверка `if (this != &other)`?

Проверка защищает от присваивания объекта самому себе:

```cpp
a = a;
```

Без неё можно сначала удалить собственные данные, а затем попытаться скопировать их из уже освобождённой памяти.

### 9. В каком порядке вызываются деструкторы для объектов, созданных в обратном порядке?

Деструкторы вызываются в порядке, обратном созданию объектов.

Если объекты созданы в порядке `A`, `B`, `C`, то уничтожаться они будут в порядке `C`, `B`, `A`.

### 10. Что такое глубокое и поверхностное копирование?

**Поверхностное копирование** копирует значения полей, включая адрес указателя. Несколько объектов начинают использовать одну область памяти.

**Глубокое копирование** создаёт отдельную область памяти и копирует в неё сами данные:

```cpp
data = new int[size];

for (int i = 0; i < size; ++i) {
    data[i] = other.data[i];
}
```

### 11. Для чего нужен метод `reserve()` и чем он отличается от `resize()`?

`reserve()` изменяет вместимость контейнера, но не меняет количество элементов.

```cpp
vector.reserve(20);
```

`resize()` изменяет количество элементов:

```cpp
vector.resize(20);
```

Если размер увеличивается, создаются дополнительные элементы.

### 12. Как организовать автоматическое расширение массива при добавлении элементов?

Перед добавлением элемента нужно проверить, хватает ли вместимости. Если места нет, выделить больший массив, скопировать данные и освободить старый:

```cpp
if (size == capacity) {
    capacity *= 2;

    int* newData = new int[capacity];

    for (int i = 0; i < size; ++i) {
        newData[i] = data[i];
    }

    delete[] data;
    data = newData;
}

data[size++] = value;
```

### 13. Что такое RAII?

**RAII** - принцип, при котором ресурс связывается с временем жизни объекта.

Ресурс захватывается в конструкторе, а освобождается в деструкторе. Благодаря этому память автоматически освобождается даже при возникновении исключений.

### 14. В каких случаях может возникнуть утечка памяти в классе `IntVector`?

Утечка возможна, если:

- забыть вызвать `delete[]` в деструкторе;
- выделить новую память и потерять указатель на старую;
- при расширении массива не освободить старый массив;
- в конструкторе или методе возникнет исключение после выделения памяти;
- неправильно реализовать оператор присваивания.

### 15. Что такое `const`-методы и зачем они нужны?

`const`-методы не изменяют состояние объекта:

```cpp
int getSize() const {
    return size;
}
```

Они могут вызываться для константных объектов:

```cpp
const IntVector vector;
vector.getSize();
```

Такие методы помогают контролировать изменение данных и делают интерфейс класса безопаснее.
