=== Сложность операций Stack<T> ===
push: O(1) амортизированно, O(n) при расширении
pop: O(1), top: O(1), isEmpty: O(1), size: O(1)
Оценки даны при постоянной стоимости операций над T.

=== Stack<int>: рост и порядок LIFO ===
До добавления: размер = 0, пуст = true
push(10): размер = 1, top = 10
push(20): размер = 2, top = 20
push(30): размер = 3, top = 30
push(40): размер = 4, top = 40
push(50): размер = 5, top = 50
top через const-ссылку: 50, размер = 5
Извлечение в обратном порядке: 50 40 30 20 10
После извлечения: размер = 0, пуст = true
Повторное использование: pop = 99

=== Другие типы данных ===
push(top()) с расширением: top = один, размер = 2
Stack<string>: pop = два, следующая вершина = один
Stack<double>: top = 2.75, pop = 2.75, размер = 1

=== Граничные случаи ===
pop пустого стека: Стек пуст
top пустого стека: Стек пуст
После ошибок: размер = 0, пуст = true
Начальная ёмкость 0, два push: размер = 2, top = 2
