=== Часть 1. Рекурсивные алгоритмы ===
0!: recursion = 1, loop = 1
1!: recursion = 1, loop = 1
5!: recursion = 120, loop = 120
20!: recursion = 2432902008176640000, loop = 2432902008176640000
F(0): memo recursion = 0, loop = 0
F(1): memo recursion = 1, loop = 1
F(10): memo recursion = 55, loop = 55
F(93): memo recursion = 12200160415121876738, loop = 12200160415121876738
Строки ASCII, регистр и пробелы учитываются:
"": reverse = "", palindrome = true
"a": reverse = "a", palindrome = true
"algorithm": reverse = "mhtirogla", palindrome = false
"level": reverse = "level", palindrome = true
"Level": reverse = "leveL", palindrome = false
Отрицательный факториал: Аргумент не может быть отрицательным
21!: Результат не помещается в uint64_t
Отрицательный индекс Фибоначчи: Аргумент не может быть отрицательным
F(94): Результат не помещается в uint64_t
Текст UTF-8: Ожидается строка ASCII
Слишком длинная строка: Допускается не более 4096 символов
